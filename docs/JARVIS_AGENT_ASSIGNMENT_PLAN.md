# JARVIS Agent Assignment Plan

## Purpose

Define how coding agents should execute JARVIS development.

## Agent Roles

## Architecture Agent

Responsibilities: - Review specs - Validate design - Maintain
architecture consistency

## Backend Agent

Responsibilities: - Go runtime - Services - APIs - Core infrastructure

## Frontend Agent

Responsibilities: - Electron - UI - Desktop features

## Intelligence Agent

Responsibilities: - Agents - Prompts - LLM integration - Memory

## Tooling Agent

Responsibilities: - Tools - Integrations - Automation

## QA Agent

Responsibilities: - Tests - Validation - Regression checking

## Rule

Agents should work only from approved specs.
