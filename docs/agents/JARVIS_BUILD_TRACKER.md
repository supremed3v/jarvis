  SPEC-0009   Completed         services/core/eventbus.go: Bus, the concrete implementation filling the Container.EventBus slot SPEC-0008 reserved as a placeholder `interface{}`. EventBus interface exposes Publish(event) and Subscribe(eventType, handler) (unsubscribe func()); Bus delivers to each subscriber on that subscriber's own dedicated goroutine reading off a bounded buffered channel (default 64, overridable via WithSubscriberBufferSize), so Publish itself never blocks — a full subscriber buffer drops that subscriber's copy of the event (and logs a warning if WithBusLogger is set) rather than stalling the publisher or other subscribers.
