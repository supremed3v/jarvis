# Claude Code Rules

## Purpose

Define execution rules for Claude Code agents working on JARVIS.

## Rules

-   Always read relevant specifications before coding.
-   Never implement features outside approved specs.
-   Ask for clarification when architecture decisions are unclear.
-   Preserve existing architecture decisions.
-   Prefer small incremental changes.

## Code Standards

Require:

-   Clean structure
-   Tests for new functionality
-   Documentation updates
-   Error handling

## Completion Requirements

A task is complete only when:

1.  Implementation exists
2.  Tests pass
3.  Documentation is updated
4.  Changes match specification
