# Feature Completion Checklist

## Before Merge

Architecture:

-   [ ] Feature matches architecture
-   [ ] Dependencies reviewed
-   [ ] No unnecessary complexity added

Implementation:

-   [ ] Code complete
-   [ ] Error handling implemented
-   [ ] Logging added
-   [ ] Configuration added if required

Testing:

-   [ ] Unit tests
-   [ ] Integration tests
-   [ ] Edge cases checked

Documentation:

-   [ ] Specs updated
-   [ ] Usage documented
-   [ ] Decisions recorded
