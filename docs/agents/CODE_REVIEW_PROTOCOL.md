# Code Review Protocol

## Purpose

Standardize review of JARVIS changes.

## Review Areas

Architecture:

-   Does it follow system design?
-   Are boundaries respected?

Code Quality:

-   Is code maintainable?
-   Are errors handled?

Security:

-   Are permissions respected?
-   Is sensitive data protected?

Testing:

-   Are tests sufficient?

## Review Outcome

Approve only when requirements are satisfied.
