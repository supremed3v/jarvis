# specs/

SPEC-0001 lists a top-level `specs/` directory, but the actual feature
specifications for this repository live in `context/features/` (see
`context/features/FEATURE_INDEX.md`), which predates this directory and
is treated as authoritative per `CLAUDE.md`.

This directory is kept as a placeholder to satisfy the SPEC-0001
structure requirement; do not add spec content here — add or edit
`context/features/SPEC-NNNN-*.md` instead.
