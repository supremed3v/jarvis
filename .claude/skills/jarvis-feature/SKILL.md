# JARVIS Feature Workflow

Manages feature execution from specification to completion.

## Actions

- load
- start
- test
- review
- explain
- complete

All features originate from:

```
context/features/SPEC-XXXX.md
```

All active work is tracked in:

```
context/current-feature.md
```
