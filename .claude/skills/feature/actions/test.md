# Test Action

## Purpose

Validate JARVIS feature implementation.

## Steps

1. Read current-feature.md.
2. Identify modified components.
3. Review added logic.
4. Add tests where required.

## Testing Standards

Backend:

```
go test ./...
```

Frontend:

```
npm test
```

## Test Requirements

Cover:

- Happy paths
- Error handling
- Edge cases
- Integration boundaries

## Output

Report:

- Tests added
- Commands executed
- Results
- Remaining issues
