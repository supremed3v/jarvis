# Review Action

## Purpose

Verify implementation matches specification and architecture.

## Steps

1. Read current-feature.md.
2. Review git diff.
3. Compare implementation against SPEC.

Check:

- Goals completed
- Architecture compliance
- Scope control
- Security concerns
- Error handling
- Tests

## JARVIS Checks

Verify:

- Agents use approved tools
- Services respect boundaries
- Dependencies are correct
- No architecture shortcuts exist

## Output

Final verdict:

- Ready to complete
- Needs changes
