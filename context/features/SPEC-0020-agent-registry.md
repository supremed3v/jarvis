# JARVIS Agent Registry

## Overview

Create a registry responsible for storing and discovering available
agents.

## Requirements

Support:

-   Agent registration
-   Agent lookup
-   Agent removal
-   Agent listing

## Registry Usage

The runtime should be able to:

-   Find an agent by ID
-   Check capabilities
-   Route tasks

## Testing

Verify: 1. Agents register successfully 2. Agents can be discovered 3.
Duplicate registrations are handled
