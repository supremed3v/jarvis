# JARVIS Context Window Manager

## Overview

Manage information sent to LLMs within context limits.

## Requirements

Handle:

-   Conversation history
-   Memory retrieval
-   Tool outputs
-   Agent instructions

## Requirements

Must:

-   Prioritize important information
-   Remove unnecessary context
-   Track token usage

## Testing

Verify: 1. Context stays within limits 2. Important information remains
3. Large conversations are handled
