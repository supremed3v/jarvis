# JARVIS Memory Retrieval System

## Overview

Create the system that selects relevant memories during agent execution.

## Requirements

Retrieve based on:

-   User query
-   Task context
-   Agent role
-   Importance

## Requirements

Support:

-   Ranking
-   Filtering
-   Context limits

## Testing

Verify: 1. Relevant memories are returned 2. Irrelevant memories are
filtered 3. Retrieval respects limits
