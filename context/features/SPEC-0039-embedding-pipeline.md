# JARVIS Embedding Pipeline

## Overview

Create the pipeline responsible for converting information into
searchable embeddings.

## Requirements

Support:

-   Text chunking
-   Embedding generation
-   Metadata attachment
-   Storage submission

## Sources

Support:

-   Conversations
-   Documents
-   Notes
-   Code

## Testing

Verify: 1. Text is processed 2. Embeddings are generated 3. Metadata is
preserved
