# JARVIS Decision Engine

## Overview

Create a decision-making system for selecting actions.

## Requirements

Evaluate:

-   Available options
-   Risks
-   Benefits
-   User preferences
-   Constraints

## Output

Produce:

-   Recommended action
-   Reasoning
-   Confidence level

## Testing

Verify: 1. Decisions consider constraints 2. Recommendations are ranked
3. Confidence is generated
