# JARVIS Debugging Assistant

## Overview

Create debugging workflows for software issues.

## Requirements

Support:

-   Error analysis
-   Log analysis
-   Root cause investigation
-   Fix recommendations

## Workflow

    Error
     ↓
    Analyze Context
     ↓
    Inspect Code
     ↓
    Generate Hypothesis
     ↓
    Suggest Fix

## Testing

Verify: 1. Errors are analyzed 2. Context is collected 3. Solutions are
generated
