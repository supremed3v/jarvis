# JARVIS Proactive Intelligence Engine

## Overview

Create the capability for JARVIS to proactively identify useful actions.

## Requirements

Detect:

-   Upcoming deadlines
-   Important changes
-   Repeated patterns
-   Opportunities

## Safety

Proactive actions must respect permissions.

## Testing

Verify: 1. Opportunities are detected 2. Suggestions are relevant 3.
User control remains intact
