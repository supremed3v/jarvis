# JARVIS Filesystem Tool

## Overview

Create filesystem interaction capabilities.

## Requirements

Support:

-   File reading
-   File writing
-   Directory listing
-   File searching
-   Metadata retrieval

## Security

Must respect:

-   Allowed paths
-   Permission rules
-   User approvals

## Testing

Verify: 1. Files can be read 2. Files can be written 3. Restricted paths
are blocked
