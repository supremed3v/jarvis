# JARVIS Ollama Integration

## Overview

Implement Ollama as the first local LLM provider.

## Requirements

Support:

-   Connecting to local Ollama server
-   Listing available models
-   Sending prompts
-   Streaming generated tokens
-   Handling model errors

## Configuration

Support:

-   Ollama host URL
-   Default model
-   Timeout settings

## Testing

Verify: 1. Ollama connection succeeds 2. Models can be discovered 3.
Responses stream correctly 4. Errors are reported
