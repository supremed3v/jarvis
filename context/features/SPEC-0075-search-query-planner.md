# JARVIS Search Query Planner

## Overview

Create a planning layer that converts user requests into effective
search strategies.

## Requirements

Support:

-   Query decomposition
-   Multiple search queries
-   Search intent detection
-   Query refinement

## Example

User request:

Find the best local AI coding model

Planner:

-   Compare coding benchmarks
-   Check hardware requirements
-   Review community feedback

## Testing

Verify: 1. Complex requests produce multiple queries 2. Search intent is
preserved 3. Results improve from refinement
