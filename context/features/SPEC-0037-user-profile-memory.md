# JARVIS User Profile Memory

## Overview

Create persistent memory for user identity, preferences, and important
facts.

## Requirements

Store:

-   User preferences
-   Personal information
-   Working style
-   Projects
-   Important facts

Example:

    User prefers Go over Python
    User works on Invoke Solutions

## Testing

Verify: 1. User facts can be stored 2. Facts can be retrieved 3. Updates
replace outdated information
