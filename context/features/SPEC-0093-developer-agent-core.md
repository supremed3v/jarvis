# JARVIS Developer Agent Core

## Overview

Create the primary software engineering agent for JARVIS.

The developer agent assists with understanding, modifying, debugging,
and improving software projects.

## Requirements

Support:

-   Repository analysis
-   Code explanation
-   Code generation
-   Debugging assistance
-   Development workflows

## Tools

Required:

-   Filesystem tool
-   Terminal tool
-   Git tool
-   Browser tool

## Testing

Verify: 1. Agent can analyze projects 2. Agent can execute approved
tools 3. Results are returned correctly
